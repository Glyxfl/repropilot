# 如何把项目变成求职证据

## 先把项目讲成自己的

建议花时间亲手走完完整演示、改一个参数、故意制造一个失败、查看统计代码和状态机。AI 协助实现不代替理解；在面试中如实说明使用了 AI 工具，并重点解释你自己能验证和维护的设计。

项目是作品集，不等于实习。没有真实部署前，放在“个人项目”，不要编造公司、客户、用户数、节省比例或准确率。

## 简历描述：根据实际掌握程度使用

### 面向 AI 产品经理

**ReproPilot｜科研自动化 Agent｜个人项目**

- 围绕 bulk RNA-seq 从需求到交付的工作流设计原型，将自然语言任务拆成结构化分析方案、人工确认、自动执行和结果验收。
- 定义方案正确性、有效交付率和回放一致性等指标；实现固定工具能力边界、失败反馈与检查点恢复，产出可运行前端与产品设计文档。
- 基于公开 pasilla 数据完成真实差异分析，提供方法、输入指纹、工具记录及复现脚本；真实用户试用与效果指标仍待验证。

### 面向 FDE / AI 应用工程实习

**ReproPilot｜受限科研执行与交付系统｜个人项目**

- 实现 FastAPI、SQLite 与独立分析工作进程，连接模型参数规划与 PyDESeq2 计算，交付结果表、图表、报告及运行指纹。
- 通过严格参数契约、方案哈希确认和原子状态转换约束执行；在图表失败后验证并复用统计检查点，避免重复拟合。
- 编写 API、并发、设计混杂阻断与真实统计回放测试，配置 CI；在本地验证公开数据完整流程，不将原型表述为生产部署。

## 三分钟演示脚本

0:00–0:25：解释场景。实验同学提出两组比较，分析同学需要确认方法并交付产物。你的专业背景使你能检查方法是否适用。

0:25–0:55：输入默认任务，展示方案。说清 treated/reference、测序类型协变量、预过滤、padj 与 log2FC 阈值。

0:55–1:35：确认后自动执行，查看工具记录。解释模型不生成可执行代码，统计计算由固定工具承担。

1:35–2:05：打开结果报告与 ZIP。展示图表、方法、输入与版本指纹和统计复现脚本。

2:05–2:45：打开已经完成首次失败的合成演练任务，点击重试。展示 fit_deseq2 / cached，说明恢复没有改变科学方法。

2:45–3:00：说明限制与下一步。真实用户试用、R DESeq2 方法对照、授权输入接入和集群适配应由验证驱动。

首次运行耗时因机器与依赖冷启动而异。面试时可以事先跑一次，并准备已有任务结果；要明确告诉面试官哪些是现场新运行，哪些是历史记录。

## 常见追问与应能说明的内容

| 追问 | 应掌握的回答 |
| --- | --- |
| 相比聊天工具有什么价值？ | 不仅给建议，实际执行方法、验证产物并交付可回放结果；支持范围明确 |
| 这真是 Agent 吗？ | 是受限工具执行 Agent / 工作流，不是开放式自主科研系统。离线模式本质上是规则规划器 |
| 为什么不让模型直接写代码？ | 参数空间已知，固定工具更容易验证方法正确性和失败恢复；生成代码会扩大风险与验证成本 |
| 为什么必须人工确认？ | 比较方向、协变量和阈值会改变解释，不应由模型悄悄决定 |
| 批次完全混杂怎么处理？ | 阻断执行，让研究者重新判断实验设计；不会自动删除协变量以获得成功 |
| 差异基因怎么算？ | 负二项拟合、Wald、BH；padj 阈值与未收缩 LFC 过滤，两者不要混为阈值假设检验 |
| PCA 是否校正了 batch？ | 没有；图来自 log2 归一化计数的高变基因，只是探索性展示 |
| 怎么证明结果可复现？ | 固定输入与参数、核心依赖版本、独立回放脚本以及结果容差对照；不保证跨 BLAS 位级一致 |
| 如何走向实验室交付？ | 先访谈与同任务试用，再接授权数据、认证、隔离与任务调度；不承诺直接生产可用 |
| 模型准确率多少？ | 尚无真实模型标注集与实测；不能拿规则单元测试通过率冒充 LLM 准确率 |

## 接下来最值钱的行动

1. 邀请 3–5 位同门讲最近一次真实分析过程；记录日期、问题与原话，经同意后匿名整理。
2. 收集 20–30 条可授权的分析需求，由你标注比较方向、协变量、阈值和超范围类型；比较离线与真实模型的参数准确率和拒绝质量。
3. 做一次真实同任务对照，测量从需求明确到有效交付的时间与人工介入次数。结果可能不优于现有脚本，照实分析原因。
4. 阅读和修改核心代码后录制 2–3 分钟演示，在 README 放录屏链接。准备“失败—判断—改进”的具体例子。
5. 根据岗位 JD 调整重点：产品岗展示发现问题与取舍，FDE 展示输入/系统边界、集成、验收与运维。不要把简历写成技术名词清单。

项目无法保证拿到实习，但可把“我对 AI 感兴趣”变为招聘方能运行、检查和追问的具体作品。
